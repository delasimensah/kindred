## Design system (locked)

- **Palette source:** https://colorhunt.co/palette/222831393e46ffd369eeeeee
- **Primary:** `#FFD369` (button text `#222831`)
- **Neutrals:** page `#222831`, surface `#393E46`, text `#EEEEEE`, secondary text `#EEEEEE` at ~60% opacity
- **Accent:** founding / impact chips — `#FFD369` on `#393E46`
- **Typography (mobile):** Clash Display 600/700 for display; Satoshi 400/500/600/700 for UI. Titles 20–24px, body 16px, meta 13–14px; display 28–36px
- **Typography (web):** same families. Page titles 28–32px Bold; sections 18–20px SemiBold; body 15–16px; tables 13–14px; studio metrics 32–40px Clash Display
- **Layout:** list rows 8–12px inside; sections 20–24px; artwork/cards/buttons 12px radius; inputs 10px; capsules for pills and mini-player; soft shadow under glass only; 44px targets
- **Differentiator:** Dark mode
- **Anti-style:** No purple/lavender gradients; no cream+terracotta template; no Apple red / Spotify green / SoundCloud orange / teal; no coffee-brown page; no light white mobile shell; no fake solid glass; no lyrics, tip jars, social login, 3D mascots, “test user”
- **Product-specific:** Kindred wordmark; USD $4.99 / $9.99; demo earnings labelled; seed names; mobile craft bar; web no purchase / no offline / no craft
